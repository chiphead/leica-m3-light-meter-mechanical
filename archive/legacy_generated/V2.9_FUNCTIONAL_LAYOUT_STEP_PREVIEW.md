# V2.9 Functional Layout STEP Preview

Status: **conceptual packaging preview only**. Not a released enclosure, not a manufacturing model, and not a validated fit.

Branch: `cla`
Generator: `generate_v2_9_functional_layout_preview.py`
Dependency: CadQuery >= 2.4

## Purpose

Create a first visual STEP assembly using the current functional-side constraints, rather than reusing the superseded V2.0 display placement. This preview is intended to inspect broad component placement and communicate the architecture.

## Preserved functional relationships

- Landscape Waveshare ESP32-S3-LCD-1.47B is placed on the left.
- USB-C is on the left edge and faces outward to -X.
- TSL2591 is vertical at the front, with its sensing face toward +Y.
- AS5600 PCB is horizontal with its package facing downward.
- AS5600 package, magnet and bottom rotor share the same nominal axis.
- Bottom rotor is represented as one fused conceptual part.
- E8H7-6.5J30-9B15-F200 is a separate horizontal-shaft side control; it is not coupled to the AS5600 rotor.

## Coordinate convention

- LCD glass outer face: Z=0 datum.
- +Z: toward the top-cover exterior.
- +X: right across the landscape display.
- +Y: toward the front of the meter.
- USB-C: left side (-X).

## Provisional values

The generator contains coarse envelopes inherited from earlier studies: LCD module 37×21×8 mm (approximate and requires remeasurement), USB shell 9×3.2×3.5 mm, AS5600 PCB 23×23×1.6 mm, package 2×2×1.5 mm, magnet Ø6×2 mm with 1 mm nominal gap, TSL PCB 16×19×5 mm, and E8H7 body 7.8×6.9×6.5 mm. These are not all measured values. In particular, E8H7 body height, shaft projection, magnet choice and sensor gap remain unresolved.

## Explicit omissions

- No production enclosure, lid, cold shoe or battery.
- No PCB support or validated structural load paths.
- No thrust washers, retainer, bushing retention or final rotor clearances.
- No optical baffle or validated TSL2591 aperture.
- No cable insertion/bend/access envelope beyond the crude connector shell.
- No interference, tolerance, stress, thermal or physical-fit validation.

The earlier V2.0 macro remains a historical reference and is not the current integrated layout baseline. V2.6 documented its 0.3 mm nominal LCD/floor Z overlap; this preview does not claim to resolve that issue.

## Regeneration

Run from this directory with CadQuery installed:

```bash
python generate_v2_9_functional_layout_preview.py
```

Outputs are written beside the script:

- `V2.9_FUNCTIONAL_LAYOUT_PREVIEW.step`
- `V2.9_FUNCTIONAL_LAYOUT_PREVIEW.stl`

No FreeCAD macro execution is claimed. STEP export was performed with CadQuery in the generation environment; the generated local artifact is not automatically present in this GitHub commit.
