# Legacy generated mechanical design archive

All files in this directory were moved from the former active `mechanical_design/` workspace.

They are retained for historical reference only. They are **not** the current enclosure design, not an approved manufacturing baseline, and must not be used to overwrite or reconstruct the user's manually designed model.

The archive may contain obsolete dimensions, assumptions, component arrangements, FreeCAD macros, and conceptual STEP-generation scripts. Consult these files only when the user explicitly asks to compare historical concepts or recover a specific design idea.

The former workspace README is preserved as `WORKSPACE_README.md`.
