# V0.7 sensor-module reference CAD

Run `build_v07_sensor_reference.FCMacro` in FreeCAD (Macro → Macros → Execute).

Outputs:
- `V0.7_Sensor_Module_Reference.FCStd`
- `V0.7_Sensor_Module_Reference.step`

## Included
- Vertical TSL2591 PCB envelope with its optical face directed toward +Y/front.
- Front-wall coupon with a true through optical aperture.
- Hollow rectangular baffle/tunnel reference.
- Horizontal AS5600 PCB envelope with the sensor package on the underside, facing downward.
- Magnet reference below the sensor package and a visible gap witness.

## Optical design warning
The rectangular aperture and hollow tunnel in this macro are placeholders only. They are not copied from a validated optical design and must not be treated as a finished baffle. See [OPTICAL_REFERENCE_REVIEW.md](OPTICAL_REFERENCE_REVIEW.md) for the open-source reference review and the design decisions still required.

## Important status
This is a separate module-reference model, not integrated with the V0.6 display/USB assembly and not manufacturing-ready. TSL2591 board/package dimensions, aperture, baffle, AS5600 PCB/package geometry, magnet dimensions, and all placements are provisional.

The 1.0 mm package-face-to-magnet-surface gap is a layout starting value only. Confirm the actual AS5600 package projection, magnet thickness/diameter, magnetization, sensor operating range, and mechanical tolerance before release. The macro intentionally exposes this gap as a parameter.

Coordinate convention: +Y is the front direction; AS5600 sensing face points -Z/down; magnet is below it. Do not infer final whole-device coordinates from this isolated module file.
