# V0.6 CAD source

## Build the interface reference model

1. Open FreeCAD.
2. Run `build_v06_reference.FCMacro` through **Macro → Macros → Execute**.
3. The macro creates a provisional board envelope, LCD glass reference, USB-C metal-shell envelope, a plug/service-clearance envelope, and a local left-wall coupon with a true through-cut USB-C aperture.
4. It saves `V0.6_Interface_Reference.FCStd` and `V0.6_Interface_Reference.step` beside the macro.

## Important limitations

- This is an interface-reference model, not the complete light-meter enclosure.
- USB-C shell width/height/depth (9.0/3.2/3.5 mm) are provisional placeholders.
- USB-C cutout clearance (0.3 mm per side) is provisional.
- The 7.55 mm vertical relationship is the user-measured distance from the LCD glass outer surface to the **far-side lower edge of the USB-C metal shell**. It is not the internal receptacle opening edge.
- Board envelope and glass size/placement are placeholders until measured. Do not use the STEP for manufacturing.
- The wall coupon is a local aperture test piece, not the final left enclosure wall.
- Sensor, magnet, encoder, cold-shoe, and rotor geometry are intentionally not fabricated from unknown dimensions.

## Editing

Edit the parameter block at the top of `build_v06_reference.FCMacro`. The macro is dependency-free apart from FreeCAD's bundled modules.
